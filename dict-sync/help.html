📋 Dict Sync

将 dev 环境的字典配置（类型 + 值）一键同步到 test 环境

🚀 快速开始（3 步）

1
在 dev 环境采集数据

打开 dev 的字典管理页面 → 搜索你要同步的字典 → 点击右下角 📋 → 展开面板 → 点 📥 一键采集

插件会自动拉取当前搜索结果中所有字典类型及其字典值

💡 可以多次搜索、多次采集，数据会自动合并去重。已有数据重新采集会更新字段（如备注变更）

2
在 dev 页面勾选要同步的项

面板中会列出所有采集到的字典类型和值，以树形展示。勾选/取消勾选来控制哪些需要同步

  • 点分组 checkbox → 全选/全不选该组
  • 点单条 checkbox → 单独控制
  • 点 全选 → 一键全选/全不选
3
在 test 环境同步

打开 test 的字典管理页面 → 先搜索一次（让插件检测 API 地址）→ 点 📋 打开面板 → 点 📤 同步选中

插件会：先查 test 是否已有该字典/值 → 有则更新 → 无则新建。字典值按同一字典下的 value 精确匹配，不按 label 匹配；例如「年岁：year」会更新为「岁：year」，不会新增重复的 year。

🔧 面板功能说明

  • 📥 一键采集 抓取当前搜索结果 + 自动拉取值
  • 📤 同步选中 将勾选的字典和值同步到当前环境
  • 🗑 删除选中 从采集数据中移除勾选的项
  • 🗑 清除 清空全部采集数据
  • 日志区点击 ▲ / ▼ 可折叠展开
  • 📋 浮动按钮可以拖拽移动位置

⚠️ 注意事项

  • 同步前在 test 页面先搜索一次，确保插件检测到正确的 API 地址
  • 切换到 test 标签页后，打开面板会自动从存储刷新数据，无需手动刷新
  • 字典的 belongingProjectList 同步时设为空数组（因列表 API 只返回展示文本，无法还原为项目编码）
  • 同步使用 先查后改 策略：test 已有则走编辑接口，没有则走新增接口
